# Camping Croatia - Static Website

A beautiful static website for showcasing seaside camping locations in Croatia.

## Features

- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Modern UI**: Uses Materialize CSS framework with custom styling
- **Dynamic Content**: JavaScript-powered camp listing
- **Beautiful Layout**: Custom color palette with seaside theme

## Quick Start

1. Open `index.html` in your web browser
2. Browse the existing camps
3. Enjoy the beautiful seaside camping showcase

## File Structure

```
CampSiteStatic/
├── index.html              # Main page with camp listings
├── css/
│   └── styles.css          # Custom styles and theme
├── js/
│   ├── data.js             # Dummy data and storage functions
│   └── app.js              # Main application logic
└── README.md               # This file
```

## Technology Stack

- **HTML5**: Semantic markup
- **CSS3**: Custom properties and modern layout
- **JavaScript ES6+**: Dynamic functionality
- **Materialize CSS**: UI framework
- **Material Icons**: Icon library

## Deployment

Deploy to any static hosting service:
- Netlify, Vercel, GitHub Pages
- AWS S3, Firebase Hosting
- Or any web server

Simply upload the files and the site works immediately.
